# Patrimoine AI Advisor

Crée une application web appelée "Assistant Patrimoine IA".

L'application permet à un utilisateur de saisir quelques informations

financières personnelles afin d'obtenir une analyse générée par une IA.

Créer une interface moderne, professionnelle et responsive.

La page principale doit contenir :

1. Un titre :

   "Assistant Patrimoine IA"

2. Un sous-titre :

   "Analysez votre situation financière avec l'aide de l'IA."

3. Un formulaire avec les champs :

   - Revenus annuels (€)

   - Épargne disponible (€)

   - Montant du crédit immobilier (€)

   - Mensualité du crédit (€)

   - Objectif patrimonial

     (Investir, Acheter un bien, Préparer la retraite, Épargner)

4. Un bouton :

   "Analyser ma situation"

5. Une zone "Analyse IA" qui sera vide au départ.

   Elle affichera plus tard :

   - Résumé de la situation

   - Points forts

   - Points d'attention

   - Recommandations

Pour le moment, ne connecte aucune API IA et aucune base de données.

Utilise uniquement des données locales/mockées pour l'interface.

Prépare cependant le code pour pouvoir connecter plus tard Supabase

et une API externe.
